# Object-Oriented Programming - Laboratory Works

This repository contains two laboratory assignments completed as part of my university coursework in object-oriented programming (OOP). The assignments focus on operator overloading and templates, exploring key programming concepts and their practical implementation.

## Laboratory Assignments

### 1. Operator Overloading
This laboratory focuses on operator overloading, allowing operators to be redefined for user-defined types. The work explores how to implement custom operator behavior and improve the usability of classes.

### 2. Templates
This laboratory focuses on templates and generic programming. It explores the use of function and class templates to create reusable, flexible, and type-independent code.

## Technologies and Concepts

- Object-oriented programming (OOP)
- Operator overloading
- Function and class templates
- Generic programming
- Code reusability and organization

These assignments demonstrate the practical application of object-oriented programming concepts and provide experience in developing structured and reusable programming solutions.

# Объектно-ориентированное программирование - лабораторные работы

Данный репозиторий содержит две лабораторные работы, выполненные в рамках университетской программы по объектно-ориентированному программированию (ООП). Работы посвящены перегрузке операторов и шаблонам, а также их практическому применению при разработке программ.

## Лабораторные работы

### 1. Перегрузка операторов
Лабораторная работа посвящена перегрузке операторов, которая позволяет определять их поведение для пользовательских типов данных. В рамках работы рассматривается реализация собственных операторов для классов и повышение удобства работы с объектами.

### 2. Шаблоны
Лабораторная работа посвящена шаблонам и обобщённому программированию. Рассматривается применение шаблонов функций и классов для создания универсального, гибкого и повторно используемого кода.

## Технологии и концепции

- Объектно-ориентированное программирование (ООП)
- Перегрузка операторов
- Шаблоны функций и классов
- Обобщённое программирование
- Повторное использование и структурирование кода

Данные лабораторные работы демонстрируют практическое применение принципов объектно-ориентированного программирования и развитие навыков создания структурированных и повторно используемых программных решений.
